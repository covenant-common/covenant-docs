Try a deal in your browser

A deal records the terms both sides sign. This sample checks submitted evidence against its rules and shows an agreed dispute process. Those checks do not establish outside truth, delivery quality or fairness in every case.

This page runs the agreement engine inside your browser, in three steps: propose, accept, settle. Nothing is installed on your computer.

Test mode. Every key is made fresh in this page and forgotten when you leave. The money is 100 simulated test USDC on an in-page ledger: no real money, no wallet, no chain, no account. After the page has loaded, nothing is sent anywhere.

· Not started.

  1. Propose. The buyer offers a job and a price, and signs the exact terms.
  2. Accept. The seller signs the same terms. The payment moves into escrow: held, not yet paid.
  3. Settle. The seller delivers with proof. The buyer checks the proof and releases the payment.

No public package yet

This page already runs the sample in your browser. Nothing is installed and no real payment is made. There is no published package named agentic-agreements, so an install command for that name fails. Try the public tools instead, or bring one job to the pilot.

What this page is not

  • Not real value. The test USDC and the escrow exist only in this page.
  • Not a hosted service. The page, Python (Pyodide) and the package are static files from this site, each checked against a fingerprint before it runs.
  • Not the pinned runtime. In the browser the package runs on Pyodide's cryptography build, which is older than the version an installed package pins. Use an install route for anything beyond trying it.
