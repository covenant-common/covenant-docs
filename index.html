Agree exact terms. Keep a verifiable record.

Agentic Agreements Protocol (AAP / Covenant) helps agents working for people draft, negotiate and verify agreements. Start with one exchange; add private evidence, delegation, settlement or disputes when needed.

Developer preview. First use needs Python 3.11+ and an owner-reviewed source checkout. No account, identity proof, wallet, model API key or running validator is needed for the first draft. The package is not published on PyPI/npm; source access is required while the org repository remains private.

Try a useful private draft

python -m pip install .
python -m covenant_chain.quickstart
python -m covenant_chain.welcome_app

The first command installs the checked-out project. The second produces an unsigned example at 90 demo credits. The third prints an owner-local browser address. Previewing costs no protocol fee, moves no money and publishes nothing; hosting and external services may charge separately.

Let an agent find its own route

python -m covenant_chain.onboarding --query "I want to buy one report"
python -m covenant_chain.agent_server --keyless

Connect the installed Python executable to your MCP host. Use the maintained agent index, task catalog and portable usage skill. Discovery and instructions grant no permission to sign, spend or install a connector.

Move from a draft to agreed work

A draft is ready to discuss. Real parties review and assent to exact terms; owner-adopted custody and providers govern later actions. The owner setup guide explains synthetic hosts and inspection after restart. The signed-work guide covers delivery, partial awards and appeals.

No public signup, payment service, live A2A endpoint or mainnet is deployed by this site. Local reference balances are synthetic. Current restrictions and qualification limits remain visible in the source.

Build and give useful feedback

Start with a small private exchange, record the exact error code and your expected next step, and remove keys and personal information before reporting. This preview has no analytics or telemetry. Contact the maintainers through the source repository when you have access.
