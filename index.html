The reason to use it

The work can move between agents. The agreement can move with it.

A service order can pass through a storefront, chat, agent tools and a payment provider. Covenant gives the buyer, supplier and reviewer a common record of the deal—so a new agent or a disputed delivery does not require piecing the terms back together.

A few things worth knowing.

Can I use it without a blockchain?

Yes. Local drafting, signing and record checking do not require a blockchain. A chosen payment rail still determines how payment is verified; an offline signature cannot guarantee that funds were not spent elsewhere.

Can I install it today?

Request an owner-reviewed checkout or build through the pilot. The implementation is private during early access, with no public package release. You can also call the hosted public MCP without installing core code, or request private account access. There is no automatic hosted signup. Covered core commercial use, including business evaluation and internal development, requires a paid written licence. The public docs and separate browser demo retain their own licences.

What is available, and what still needs proving?

The installed implementation has local tests and fresh-agent workflow reviews. That is evidence about those versions and test conditions. Production operations, independent security review and real customer adoption are separate milestones. A signature records a statement; it does not establish delivery quality, physical title or legal enforceability. Read the availability notes.
