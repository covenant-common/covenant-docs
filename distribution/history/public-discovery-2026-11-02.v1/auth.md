# Covenant public access

Public MCP: https://jupie202020.pythonanywhere.com/mcp

The nine public search, draft and review tools need no account, token or API key. Use Streamable HTTP and MCP 2025-11-25. Discover the current schemas with tools/list. Do not send an Authorization header to this anonymous endpoint.

Private account operations use a separate scoped bearer credential from account setup. Connecting this public endpoint does not create an account or grant signing or spending authority. No OAuth issuer is advertised for this service. Keep signing keys, passwords and payment credentials out of public requests.

Setup and current availability: https://covenant-common.github.io/covenant-docs/docs/API_MCP.html
Privacy: https://covenant-common.github.io/covenant-docs/PRIVACY.html
