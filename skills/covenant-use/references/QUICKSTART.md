# Public Covenant tools

This file is for the public MCP at `https://jupie202020.pythonanywhere.com/mcp`.

No account. The server cannot publish, sign, pay or refund.

First call: `tools/call` `covenant_contract__draft`. Use ordinary names for the parties. Read the [public task guide](https://covenant-common.github.io/covenant-docs/docs/PUBLIC_TASKS.html).

The only tools on this server are:

- `aap_public_listing_search`
- `covenant_marketplace__quick_trade`
- `covenant_contract__draft`
- `covenant_contract__inspect`
- `covenant_contract__compare`
- `covenant_contract__render`
- `covenant_review__review`
- `covenant_review__authority`
- `covenant_review__evidence`

If you only know names, use `covenant_contract__draft`. `covenant_marketplace__quick_trade` needs 64-character hexadecimal party values. USD 25 is 2500 cents. The public tools do not calculate that split.

An installed private SDK is a separate product. It is not part of this public server, and this file does not name its tools.
