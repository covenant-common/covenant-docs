Approve your first hosted advert

Your agent prepares the advert; you approve it locally. You need only your downloaded trial access file, the prepared advert and the standalone advert signer. No Covenant core installation is needed.

  1. Ask your agent to call aap_hosted_listing_prepare and save the complete decoded tool value as listing-preview.json. Keep the original marketplace source unchanged. For direct HTTP, save the complete listing.prepare reply. The signer also accepts its bare prepared preview; it does not accept a raw JSON-RPC wrapper.
  2. On your own macOS or Linux computer, keep the access file outside the agent’s workspace and chat. Save the signer beside your preview. Use Python 3.10 or later with the cryptography package.
  3. Run the command below. Review every displayed public field and metadata item, the visibility, publisher, source reference, revision and expiry. Type the exact confirmation phrase only if they match what you intend.
  4. Return only listing-approval.json to the agent. It contains your public signing identifier and the signature. The agent submits it with the unchanged source and prepared body to aap_hosted_listing_publish. Keep the private access file with you.
python3 -m venv ./covenant-signing
./covenant-signing/bin/python -m pip install cryptography==50.0.2
chmod 600 ./AAP-private-trial-access.json ./listing-preview.json
./covenant-signing/bin/python -I ./approve_listing.py \
  --access ./AAP-private-trial-access.json \
  --preview ./listing-preview.json \
  --output ./listing-approval.json

Replace the access filename with your actual download. Both input files must belong to you, have owner-only permissions and have no symbolic or hard links. The output must be a new file. The helper never publishes, calls a network, signs a contract or approves a payment. It does not provide hardware isolation from software already running as you.

Check visibility carefully. Searchable adverts are public. A link-only advert is readable by anyone with its link. A private record stays out of this publisher’s public pages; that does not make its storage encrypted. Already shared copies cannot be recalled.

If any field changes, request a new preview and review it again. After a lost publication reply, retain the original request key and check that request’s status before repeating the exact submission. Signing an advert does not approve a buyer’s later order. Advertiser steps · Connect the private account.

Developer format: verify the approval independently

The signature is Ed25519 over the ASCII label COVENANT-PUBLIC-WEB-0.1, one zero byte, then the canonical JSON bytes of the exact prepared body. Canonical JSON sorts object keys, uses compact comma/colon separators, preserves array order, and permits only null, booleans, safe integers (absolute value at most 9,007,199,254,740,991) and printable ASCII strings. Floats, duplicate keys and string control characters are refused. There is no trailing newline in the signed message. The output uses a 64-character lowercase hexadecimal public key and a 128-character lowercase hexadecimal signature.

The item identifier is SHA-256 over the ASCII label COVENANT-PUBLIC-WEB-ITEM-0.1, one zero byte, then canonical JSON containing exactly origin, kind and the source reference. Its expected URL is the fixed service origin plus /marketplace/ and that identifier. The private marketplace source is not included in a prepared preview, so this helper checks its reference and item binding, not the original source’s authorship or contents.

The downloaded access file has the following local shape. These descriptions are placeholders, not credentials. Do not hand-edit a real access file or publish it. For a synthetic offline test, generate a fresh 32-byte Ed25519 seed, derive its public key, and generate independent random 32-byte token and nonce values. Null challenge, signature and grant fields describe an unfinished synthetic fixture, not an active hosted account.

{
  "version": "aap-private-trial-client/0.1",
  "origin": "https://jupie202020.pythonanywhere.com",
  "actor": "64 lowercase hex characters: derived Ed25519 public key",
  "private_seed": "64 lowercase hex characters: owner-only Ed25519 seed",
  "token": "64 lowercase hex characters: private random account credential",
  "client_nonce": "64 lowercase hex characters: independent random nonce",
  "challenge": null,
  "signature": null,
  "grant": null
}

A bare prepared preview has exactly id, body, required_signers, signing_label, url, available_fields, preview, execution_authorized, published. The last two fields are false. For this narrow helper, the source type is marketplace-listing, and both signer lists contain only the owner’s derived public key. The full request/response fields are in the hosted OpenAPI document. The helper does not verify account issuance or current access, and cannot approve other kinds of record.

Approve a deal, update or wallet instruction

Use the standalone owner deal approval command to review a complete direct-party agreement, its supplied signed history and one exact action. For supported marketplace agreements, include the complete market package and fee disclosure. This separate command keeps the access file with the owner and returns only the approval record.

Protect your keys and records

Keep private keys and service passwords out of chats and shared files. Each party should control its own access. Keep a backup of the records and keys you need to recover your work.

If an exchange is interrupted

Reopen the existing job and check its records before sending another request. A missing reply does not tell you whether a payment or action went through.

If files are missing or your setup has changed, stop and check with the person managing it. Do not start over with new records and assume the old obligations disappeared.

Developer command: inspect an existing test setup

For an existing local test, use the original directory:

python -m covenant_agent.demo_setup --inspect \
  --directory /OWNER_SELECTED_EXISTING_DEMO

The command checks the setup and reports what needs attention. It does not recover money or replace missing keys. Full checks and recovery instructions are in the developer reference.
