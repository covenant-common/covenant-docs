No public package to install.

The public website, the hosted MCP and the browser sandbox do not come from a package registry. There is no published package named agentic-agreements on pip, uv or npm. An install command using that name fails. It is not a step to copy.

What works without the Covenant package

  • Connect the public MCP. Nine search, draft and review tools, with no account.
  • Try a deal in the browser. The page runs a checked sample. It does not install software or move real money.
  • Start a private account trial in the browser when a place is open. Signing keys stay with you. The optional terminal client is with the connection options. The client needs Python 3.10 or later and the ordinary cryptography package. It does not install the Covenant core.

A reviewed checkout is separate

The broader engine is still private. A reviewed checkout or an owner-supplied build is arranged with the project; this page cannot download it. Read the public preview, bring one job to the pilot, or ask for access. Use the setup notes that arrive with that build. Commands shown there apply to the approved checkout, not to a public package name.

If the browser sandbox stops

The sandbox reports a code and a short fix on the page. It does not send the failure anywhere. The same codes are below.

  • SANDBOX_INSECURE_PAGE — the page was opened without HTTPS, so the browser cannot check fingerprints. Open it over https:// or from http://localhost.
  • SANDBOX_MANIFEST — the page could not read sandbox.json, which names the package to run. Serve the published site, not a partial copy of the source folder.
  • SANDBOX_DOWNLOAD — a file this page needs could not be downloaded. Check the connection and reload. The page loads files only from its own site.
  • SANDBOX_PYTHON_LOAD — Python in the browser did not start. Use a current browser with WebAssembly turned on, then reload.
  • SANDBOX_PACKAGE_MISMATCH — a downloaded file does not match the fingerprint this page expects. Do not run code you cannot check.
  • SANDBOX_DEMO_FAILED — a step of the test deal failed. Run it again. If it fails twice, report the code and the detail shown on the page.
