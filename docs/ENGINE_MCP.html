Connect to the Covenant engine

Use https://jupie202020.pythonanywhere.com/mcp/engine/v1 in a remote Streamable HTTP MCP client. Discovery and reviewed public actions work without an API key. The connection was checked on 14 November 2026 and reported aap-engine version 0.2 over MCP 2025-11-25.

In Cursor, add the covenant-engine entry to your project’s mcpServers settings and refresh the tool list. Keep other entries in your configuration. Download the engine configuration.

{
  "mcpServers": {
    "covenant-engine": {
      "url": "https://jupie202020.pythonanywhere.com/mcp/engine/v1"
    }
  }
}

Find the action you need

  1. covenant_onboard gives you the host’s access routes.
  2. covenant_find finds services and features. Use {"kind":"features","query":"covenant_contract__draft"} to find the drafting action by name. A broad search can surface a related concept first.
  3. covenant_explain gives you the input schema and access requirements for a named action. For contract drafting, use {"tool":"covenant_contract__draft"}.
  4. covenant_call takes the action’s tool name and an arguments object shaped by that schema.

Try asking your client to find the agreement-drafting action and prepare unsigned terms for an icon design brief. Use tools/list and the action schema to check current availability.
