Stage names

The same stages on every page.

  1. Find
  2. Agree PROPOSED
  3. Pay BOUND
  4. Deliver DELIVERED
  5. Resolve SETTLED or DISPUTED then RELEASED

Those stage names are the installed work-order checks. The public host cannot settle, hold or refund. A recorded offer or counter-offer is coming soon. The browser sample uses test funds only.

Payments and fees

USDC receipt checks on Base and Ethereum are configured, not yet verified. They are not connected, and settlement is off, so a payment cannot be completed on this host yet. You keep your keys. Card is coming soon (not connected). The posted 0.5% fee is optional for the first 14 calendar days of this launch, starting 1 November 2026. This site does not state when that window ends. It then applies to new deals in supported currencies. The payer sets fee_opt_in, default false. On a USD 25 order, with the fee left off, you pay USD 25, the seller gets USD 25, and the fee is USD 0. When the 0.5% fee applies, you pay USD 25.13, the seller gets USD 25, and the fee is USD 0.13. The exact quote is shown before approval; existing activated terms keep their fee. See payment choices.

Before wider use

The full system is not yet ready for general production use. Security review, deployment work and real-world trials are still needed before a wider release. Real payments, private records and other connected services need a setup agreed with the people using them.
