The early-access implementation goes beyond the browser example: complex agreements, markets, roles, voting, discovery and reputation, privacy, connected services, offline records and builder tools. See what you can build. Installation and access are arranged with us.

Before wider use

The full system is not yet ready for general production use. Security review, deployment work and real-world trials are still needed before a wider release. Real payments, private records and other connected services need a setup agreed with the people using them.

Commercial use

The core uses a commercial licence. Contact us before using covered core code for business, including business trials and internal development. Earlier licence grants and third-party rights remain in place. The website and standalone demo have their own MIT licences.
