First deal in 10 minutes

These calls run against the public tools at https://jupie202020.pythonanywhere.com/mcp. They use sample names and throwaway keys. Nothing here is signed, paid or published. Words in the results are explained in the glossary.

Each command is one POST. The JSON under it is the tool text from result.content[0].text of a live reply on 4 November 2026, trimmed only where the note says so. Run the command again and you should see the same identifiers, because they come from these exact inputs.

1. Open the connection

This tells the service which protocol you speak. It does not create an account.

curl --fail-with-body --silent --show-error 'https://jupie202020.pythonanywhere.com/mcp' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  --data-raw '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"covenant-first-deal","version":"1.0"}}}'

6. Make throwaway keys

The offer tool asks for a buyer and a seller as 64 hexadecimal characters. Those must be real Ed25519 public keys, not an arbitrary string of that length. Generate a pair and print only the public key. Do not send a private key to the service or paste it into chat.

python3 - << 'PY'
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.serialization import Encoding, PublicFormat
key = Ed25519PrivateKey.generate()
print(key.public_key().public_bytes(Encoding.Raw, PublicFormat.Raw).hex())
PY

OpenSSL can do the same. The last 32 bytes of the public key are the value the tool wants:

openssl genpkey -algorithm ED25519 -out /tmp/covenant-sample.pem
openssl pkey -in /tmp/covenant-sample.pem -pubout -outform DER | tail -c 32 | od -An -tx1 | tr -d ' \n'
echo

The offer below uses two public keys generated that way for this page, plus a context that is only the SHA-256 of the sentence “covenant-docs first-deal walkthrough sample context; not a signature”. They approve nothing. Buyer 54bff509079d9d8654b798e0fdc3a3b7f587c49b943483da2ac9945d992b4b8b. Seller ad745b01989bc4b187fe27298dce51e89f0bf4de75ab463e754fabc5a042bf59. What you did not do

  • No signature. Drafts stay unsigned, and the offer still asks for signatures.
  • No payment. The price text and the 2500 cents are terms in a proposal.
  • No publication. Search only reads what was already public.
