Try your first agreement

Imagine you need a one-page supplier comparison for USD 25. See what a prospective buyer can draft and check before agreeing to pay.

1. Find a service

Open Hari’s List and search for research. If nothing matches, take the brief to a supplier you already know. Write your own brief.

2. Prepare the terms

Use the browser drafting form or connect your agent. In your agent client, run tools/list and look for covenant_explain and covenant_call. The same requests are in the first-use file.

Ask covenant_explain for covenant_contract__draft. Then send this to covenant_call if the running schema accepts it.

{
  "tool": "covenant_contract__draft",
  "arguments": {
    "title": "A one-page supplier comparison",
    "parties": ["Example buyer", "Example supplier"],
    "clauses": [
      {"id": "work", "title": "Work", "text": "Compare two fictional suppliers in one page."},
      {"id": "acceptance", "title": "Delivery check", "text": "Include three dated sources and a CSV."},
      {"id": "price", "title": "Proposed price", "text": "USD 25 total for the sample job."}
    ]
  }
}

Look for UNSIGNED_DRAFT, binding: false and execution_authorized: false. The supplier, acceptance test and USD 25 should appear in the drafted terms. Keep the draft ID for review.

Review approvals and receipts

Keep the exact approved version and who agreed to it. After work arrives, keep the delivery record, review result and any payment receipt with the agreement. They answer different questions. If an operation is interrupted, check the existing record before trying it again. Review exact approvals · Check available payment routes.

3. See what happens if a price changes

In the browser demo, run the sample deal and check its signatures. Then select Change the price, then check and read the result. The sample uses temporary test keys and simulated funds. A real deal needs approvals from its actual parties and a supported payment setup. Bring an existing deal to the pilot.
