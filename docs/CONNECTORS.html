One useful first request

“Draft a $25 research brief. Ask me for the scope, deadline and how I will review it. Show the proposed terms. Do not sign or pay.” With the fee left off, you pay $25, the seller gets $25, and the fee is $0. When the 0.5% fee applies, you pay $25.13, the seller gets $25, and the fee is $0.13.

For one buyer and one seller in a single call, ask for covenant_marketplace__quick_trade: “Prepare an unsigned quick trade for a one-page research brief at USD 25, which is 2500 cents. When the 0.5% fee applies, you pay USD 25.13, the seller gets USD 25, and the fee is USD 0.13. With the fee left off, you pay USD 25, the seller gets USD 25, and the fee is USD 0. Use sample parties, show the returned terms, and do not sign or pay.” Price is an integer in the asset’s stated unit. Buyer, seller and context use 64-character hexadecimal values. Keep the next step clear

  • Use only the supplied schema. A review case is not the same object as an unsigned contract draft; the review reference shows the shape.
  • If no proofs were supplied, report “no proofs supplied”. Do not turn an empty check into verified approval.
  • Public role labels do not confer spending authority. Changed terms require fresh approval.
  • The three tested malformed review inputs now return specific format or identifier errors. Follow their corrective steps. If any other response says “outcome unknown”, stop and reconcile it; do not infer a signature, payment or completed job.
  • To advertise or keep private orders, use the separate account setup. The public plugin does not request its credentials.

Terminal client for the same trial

The small trial client creates or resumes the same account setup as the browser trial. It needs Python 3.10 or later and the cryptography package, with no Covenant core installation. It saves private files and prints only account details and file paths.

python -m pip install cryptography
python start_trial.py --output ./my-private-covenant-access
# If a request was interrupted, keep the same files:
python start_trial.py --output ./my-private-covenant-access --resume
