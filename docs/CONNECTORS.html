Keep the next step clear

  • Use only the supplied schema. A review case is not the same object as an unsigned contract draft; the review reference shows the shape.
  • If no proofs were supplied, report “no proofs supplied”. Do not turn an empty check into verified approval.
  • Public role labels do not confer spending authority. Changed terms require fresh approval.
  • A current bridge error can say “outcome unknown” for invalid review input. Stop that review, explain the error and check its input shape. Do not treat it as a payment, signature or completed job.
  • To advertise or keep private orders, use the separate account setup. The public plugin does not request its credentials.
