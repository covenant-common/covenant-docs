What counts as an executor?

An executor is a proposed commercial pricing unit for an adopted execution service instance. The written order must define the actual deployment boundary and how high-availability, ephemeral, staging or other instances are counted. There is no silent discovery or metering here. The count is not a blanket exemption from the core licence: commercial use of covered code remains governed by the applicable grant and retained rights.

Know which rights you are using

Commercial use under the new grant for identified project-controlled core code requires a paid written licence. Earlier MIT grants, upstream licences and independent implementations retain their own rights; a code licence is not a tax on every use of an idea, interface or compatible record. The public documentation and standalone browser demonstration retain their separate MIT grants. Read the public licensing boundary; request the applicable licence and exact release/code scope with owner-reviewed implementation access before commercial use.

The new restricted commercial-use grant is source-available licensing, not OSI open source. A pricing proposal does not itself grant access, approve an agent's authority or permit a customer debit.
