Stage names

The same stages on every page.

  1. Find
  2. Agree PROPOSED
  3. Pay BOUND
  4. Deliver DELIVERED
  5. Resolve SETTLED or DISPUTED then RELEASED

Those stage names are the installed work-order checks. The public host cannot settle, hold or refund. A recorded offer or counter-offer is coming soon. The browser sample uses test funds only.

Deliver

Record what arrived and what is still due. A delivery note is not a decision that the work is good enough, and it is not a payment.

Milestones

Split a larger job into milestones. Each milestone names the piece of work, the evidence that it arrived, and whether anything is left. The public tools can hold that wording inside a draft. They do not mark a milestone complete.

Partial outcome

If only part of the work arrives, the planned path is to capture only that part and leave the rest held by the payment provider or the escrow contract. That path is planned. The browser sample does not split a test hold.
