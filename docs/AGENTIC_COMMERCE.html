Stage names

The same stages on every page.

  1. Find
  2. Agree PROPOSED
  3. Pay BOUND
  4. Deliver DELIVERED
  5. Resolve SETTLED or DISPUTED then RELEASED

Those stage names are the installed work-order checks. The public host cannot settle, hold or refund. A recorded offer or counter-offer is coming soon. The browser sample uses test funds only.

What works today

The public tool connection is live and read-only. It can search and draft. It cannot sign, publish, pay or refund. Everything else in the table is a library check, a sandbox practice, or planned. can_pay is false.
