Disputes and refunds

Reach this page from Disputes & refunds in the menu on every page.

What to do

  1. Keep the exact terms both sides approved.
  2. Write what is missing or wrong, in plain language.
  3. Keep the evidence next to that note: the file you received, the date, and the message that sent it.
  4. On the hosted service, a dispute is a signed record between the buyer and the seller. It does not pull money back.
  5. In the browser sample only, you can open a dispute and refund the test funds. Try the sample.

Who decides

On the hosted USDC path, the buyer and the seller sign the dispute record. The fee recipient is not required to co-sign that buyer-and-seller dispute. There is no named arbitrator on this host. The browser sample has a resolver, and that resolver only moves test funds.

Partial outcomes and milestones

A job can be partly done. Record which milestone arrived and which is still missing. Listed in sandbox.works_in_test. An outside HTTP caller can offer and accept. The registry does not list an HTTP approval role or a dispute role, so that caller cannot fund or resolve. Not real funds, and not Live. This browser sample can release or return its whole test hold. It does not split a hold, and it does not reclaim part of a hold.

Keep the evidence with the milestone: the file, the date, and the message that sent it. A receipt chain, when one exists, names the note before it. Keep that note with the deal.

Timelines

  • Dispute window: Not set yet. The owner will confirm this
  • Evidence window: Not set yet. The owner will confirm this
  • Capture deadline: Not set yet. The owner will confirm this

No day count is set. Until the owner sets one, the server sandbox authority table lets the buyer or the seller open a dispute after release, with no time limit. That is what the sandbox does today. It is not a published window. Reclaim moves test money in that sandbox, and it also has no day count.

Refunds

There is no escrow on the hosted USDC route. A completed transfer is final. Covenant cannot refund it. The browser sample can return held test USDC to the buyer. That return is not a hosted refund.
