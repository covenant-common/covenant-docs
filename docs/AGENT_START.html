Give your agent a clear way to make agreements.

AAP gives agents tools to propose work, compare offers and keep a record of what each party accepts. You decide what your agent is allowed to do.

Choose an agreement or delegated workflow, market or auction, discovery task or custom layer. The public demo exercises a small two-party agreement; the invited implementation contains the broader tools.

Get an approved checkout or build before connecting your agent. There is no public registry package or hosted signup yet. Covered core business trials, development and internal use need a paid written licence; the public demo remains separately MIT licensed. See setup and licensing.

Start with an ordinary request

For example: “Help me buy a research report. Keep a record of the price, the deadline and what the supplier promises to deliver.”

A connected agent can find the right starting point, prepare a draft and show you what still needs deciding.

What your agent can help with

  • Compare offers and show what changed.
  • Prepare a clear agreement for approval.
  • Keep the delivery and payment records with the job.
  • Show what is finished and what still needs attention.
  • Prepare linked work, roles, stages or market terms using the selected preview tools.
  • Find reusable resources or pass a task to an installed connector.

See the capability map. Connect each payment provider, identity service or device deliberately; a discovered tool does not grant permission to act.

Keep control of the important decisions

You set who can approve a deal. Connecting an agent does not give it permission to sign or spend. If you want it to act for you, agree its limits first.

Your developer can connect AAP to the agent and services you already use. If a service needs a new connection, we can discuss that as part of the pilot.

Developer details: connect a local agent

First obtain an approved build. The package is not available through a public package registry yet. From the supplied checkout and prepared Python environment:

python -m pip install .
python -m covenant_chain.agent_server --keyless

This starts the local agent tools. In a connected MCP client, ask for a guide to a task:

{"tool":"covenant_onboard","arguments":{"action":"guide","parameters":{"query":"I want to buy one report"}}}

Use the guide with an exact task ID when the ordinary-language request is ambiguous. The task-catalog snapshot maps workflows to tools; ask the installed host for its current schema before calling it. Preparing a draft does not sign it, reserve funds or run a service.

After an approved installation, inspect task guidance or discover the installed tools:

python -m covenant_chain.onboarding --task paid-work
python -m covenant_chain.agent_server --keyless --stateless --discover
