Words the tools use

These meanings come from Covenant’s own pages and from the fields a public tool actually returns. A shorter page does not add a new rule.

AAP
Agentic Agreements Protocol. The FAQ says Covenant, also called AAP, helps people and their agents agree on work and keep a record of the deal. The technical status page describes it as the agreement and evidence layer under the product.
MCP
The remote tool connection. On the start page the public address is added to an agent client that supports remote HTTP MCP. The public tools need no account or key. Connecting does not sign, publish or pay. See the API and MCP guide.
Hari’s List
The public marketplace of services their owners chose to advertise. The Matrix page uses this name for that search. A listing there is not proof of stock, identity, performance or payment.
Matrix
Hari’s Matrix: the marketplace plus a map of the rest of the system, from one advert to a more complex agreement. It is a page on this site, not a separate product.
Terminal
The service browser. It shows current public adverts in a simple list. “Find a service” in the navigation opens that page.
binding: false
The draft tool returns binding set to false. The public tools guide says a draft does not bind a party. False means the result is not an accepted agreement.
UNSIGNED_DRAFT
The status on a contract draft. The saved public review of that tool expects the result to carry this status together with binding false. It is a proposal, not a signed deal.
execution_authorized
Returned false on a public draft, comparison and rendered copy. The tool descriptions say these actions never supply assent. False means the call did not authorise anyone to carry the work out.
legal_effect: NOT_DETERMINED
A field on the unsigned draft. The public pages do not treat a draft as a legal conclusion. NOT_DETERMINED is the value the draft tool returns for that field.
requires_fresh_assent
The compare tool returns this as true when the terms differ. The public task guide says changed terms need fresh assent, and the comparison does not replace or approve an agreement. The earlier draft does not approve the new text.
Envelope and CID
A content identifier (CID) is the fingerprint of exact bytes. The work-order reference says the envelope CID pins one lifecycle snapshot, and a separate agreement hash identifies the agreed terms. A CID is not the file itself, and a matching CID is not proof that no later agreement exists. The public draft’s id is that kind of fingerprint for the draft you supplied.
expected_heads
An optional input on the authority check. The published tool schema describes it as optional retained sorted causal heads for the group review. Each entry is 64 hexadecimal characters. Omitting it does not grant authority.
Projections
Capabilities says a public projection contains only the fields approved for publication. The draft tool sets machine_enforcement to ONLY_SEPARATELY_INSTALLED_AND_ADOPTED_PROJECTIONS. The same page says an adopted provider is one the owner has explicitly chosen. The public draft does not turn those projections on.
missing
On a draft, a list of gaps such as SETTLEMENT_UNSPECIFIED and DISPUTE_PROCEDURE_UNSPECIFIED. They name what you did not supply. They do not fill those terms in for you.
Sandbox error codes
The browser sample reports these codes. The wording is the page’s own:
  • SANDBOX_INSECURE_PAGE — the page was opened without HTTPS, so the browser cannot check fingerprints. Open it over https:// or from http://localhost.
  • SANDBOX_MANIFEST — the page could not read sandbox.json, which names the package to run. Serve the site that tools/build_sandbox.py built, not the source folder.
  • SANDBOX_DOWNLOAD — a file this page needs could not be downloaded. Check the connection and reload. The page loads files only from its own site.
  • SANDBOX_PYTHON_LOAD — Python in the browser did not start. Use a current browser with WebAssembly turned on, then reload the page.
  • SANDBOX_PACKAGE_MISMATCH — a downloaded file does not match the fingerprint this page expects. Rebuild the site so the page and its files match. Never run code you cannot check.
  • SANDBOX_DEMO_FAILED — a step of the test deal failed. Run the demo again. If it fails twice, report the code and the detail shown.
