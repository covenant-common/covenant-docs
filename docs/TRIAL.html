Save your access. Connect your agent.

Keep these files private. Do not paste them into an agent chat, issue or public repository.

  1. Save the private access file. It contains your signing key and the account token. The separate connection file contains the access token only, not the signing key.
  2. Import the connection file into your agent client, or copy its address and access token into the client’s private settings. Follow the private import and read-only connection check.
  3. Ask your agent: “Prepare one advert for my service using the account listing tools. A separate job contract is optional. Show me exactly what becomes public before publishing.”

To approve an advert, take its prepared preview to Review and approve an advert in your browser, or run the local owner command with your private trial file. No core installation is needed. Return only the resulting approval JSON to your agent. The account credential does not approve a deal or payment for you.
