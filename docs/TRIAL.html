Starting from another agent or a terminal?

The small trial client creates or resumes the same account setup. It needs Python 3.10 or later and the cryptography package, with no Covenant core installation. It saves private files and prints only account details and file paths.

python -m pip install cryptography
python start_trial.py --output ./my-private-covenant-access
# If a request was interrupted, keep the same files:
python start_trial.py --output ./my-private-covenant-access --resume
