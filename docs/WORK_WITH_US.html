Before you contact us

GitHub issues are public and require sign-in. Do not post secrets, personal records, private agreements or confidential business information. An email address is a contact route, not permission to send credentials or sensitive records.

The public repository contains MIT-licensed documentation. The reference implementation is currently private. Source access, services, funding and any contribution compensation are separate decisions. A message or application does not create an account, commitment or contractual right.
