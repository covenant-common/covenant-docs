A useful first message

Tell us who you are, what you want to do and the problem you want to solve. For a service or pilot, include the tools you use and one result that would make a trial worthwhile. A developer or platform buying infrastructure and support is different from an end user buying one report; tell us which role you have.

For context: capabilities · pilots · building with Covenant · partnerships · investors · common questions.

GitHub is optional and public.

If you prefer a public discussion, use the pilot form, integration form, collaboration form or website feedback form. Include only information you are happy to publish.

Start without sensitive information.

Keep passwords, keys, customer records and confidential agreements out of your first message. Email a short outline so we can arrange how to discuss sensitive details.

Implementation access is by invitation. Access, costs, setup, licences and paid work are agreed separately. Mary Mount Research is a working name; the supplier’s identity will be fixed in the written agreement before a paid trial or licence. See licensing information.

Codebase and intellectual property enquiries

To discuss acquiring the codebase and intellectual property we control, use the separate acquisition enquiry. Any sale needs agreed terms and must respect existing licence grants and third-party rights.

The free browser demo is hosted by the project maintainer under the jupitersstring GitHub account. It is the Covenant demonstration, with sample money and no live agents or payments.
