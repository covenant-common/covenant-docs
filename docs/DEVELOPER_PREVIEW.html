Stage names

The same stages on every page.

  1. Find
  2. Agree PROPOSED
  3. Pay BOUND
  4. Deliver DELIVERED
  5. Resolve SETTLED or DISPUTED then RELEASED

Those stage names are the installed work-order checks. The public host cannot settle, hold or refund. A recorded offer or counter-offer is coming soon. The browser sample uses test funds only.

Connect your agent to Covenant.

Start with one useful task: buy a report, arrange a freelance job or agree to use a file. You can also build a staged supplier workflow, a marketplace or a specialist connector. Choose the parts in the capability map, then agree one useful first test.

The browser workflows and downloadable package are standalone MIT examples covering simple deals, delegation, three-party approvals, offers and dispute review. The full implementation is available by invitation through an approved checkout or build. Covered core business evaluation, development and internal use require a paid written licence. See licensing and proposed pricing; the core has no public package-registry release. The separate public hosted MCP needs no account, and automatic private account trials are available when places remain.

A small first project

  1. Get access. Tell us what you want to build. We provide the approved build and setup notes for your pilot.
  2. Prepare an agreement. Set out the work, price, deadline and who needs to approve it.
  3. Try a change. Change the price or scope and check that the new terms need fresh approval.
  4. Follow the job. Add a delivery record and check what remains to be done.

Developer commands: run a first local example

Use the Python version and setup notes supplied with your build. The package is not published to a public registry yet. In an approved checkout:

python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
python -m covenant_chain.quickstart

The example prepares a draft using sample data. It does not send a payment. To connect a local agent client:

python -m covenant_chain.agent_server --keyless
