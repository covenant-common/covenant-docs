# Covenant engine access

Engine MCP: https://jupie202020.pythonanywhere.com/mcp/engine/v1
Aliases: https://jupie202020.pythonanywhere.com/mcp and https://jupie202020.pythonanywhere.com/mcp/agent/v1

Start with covenant_onboard, covenant_find, covenant_explain and covenant_call. Discovery and reviewed keyless actions need no account, token or API key. Use Streamable HTTP and MCP 2025-11-25. Refresh tools/list and inspect the selected action schema.

covenant_call can route account writes. Those actions require your current scoped bearer grant, checked again on every request. Set it only in private client credential settings. No OAuth issuer is advertised. Connecting creates no account or signing or spending authority. Keep private signing keys out of requests. Existing signatures and idempotency rules still apply.

All 205 maintained families are discoverable. Some require owner setup, external providers, hardware or SDK access, or remain unresolved. A directory entry does not enable them. The four entry tools expose schemas and access routes. Sandbox actions execute only at /mcp/sandbox/v1 with separate role-scoped test tokens and fictional balances.

The hosted service receives the parameters sent in each call. Keep private inputs, proving witnesses and commitment openings in reviewed local tools; share only intended proof envelopes and records. Templates and plans remain unsigned and unadopted. Group preparation does not create a forum.

The original nine public action names remain callable. Historical schemas: https://covenant-common.github.io/covenant-docs/distribution/history/public-discovery-2026-11-02.v1/mcp/tool-inventory.json
